# Dados

Coloque aqui, em `data/paysim/`, o CSV do dataset
[PaySim](https://www.kaggle.com/datasets/ealaxi/paysim1) (`PS_20174392719_1491204439457_log.csv`).
O jeito mais simples é `python -m scripts.dados.preparar_paysim --zip <zip baixado>` ou `--kaggle`.
O conteúdo desta pasta não vai para o Git. Instruções completas no README principal (seção Dados).
